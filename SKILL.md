# Review an announcement

Read the source announcement and the supplied factual source. Separate factual
claims from editorial wording.

Check the claims using `references/checklist.md`. For each mismatch, identify the
original wording, the correct fact and the source file. When information is absent,
ask a question or mark the gap; do not complete the text with a guess.

Correct confirmed errors and wording that needs correction. Preserve the meaning
and a plain working tone. Do not add marketing promises.

Format the review and corrected text using `assets/review-template.md`. Save the
result in a location allowed by the current project's rules.

Before finishing, recheck every date, time and condition in the corrected text
against the factual source. This skill prepares a draft; it does not publish it.

"If a joining link is absent, write 'Joining link not provided' and do not generate a link." Preserve its name, description and existing check steps.
