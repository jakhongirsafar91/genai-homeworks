# Project rules

This is a teaching project containing fictional data.

- Use English for this project.
- Use `source-facts.md` as the factual source for announcements. Do not add dates,
  numbers or conditions absent from that file. Mark unknown information explicitly.
- Preserve source files. Write new results only inside `drafts/`.
- Prepare drafts. Do not publish or send messages; do not connect external services
  without a separate instruction from the person supervising the task.
